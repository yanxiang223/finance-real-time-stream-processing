# 架构说明 - 实时流处理

## 概述

本实践实现了一个实时流处理参考架构，演示如何从数据源接入、事件处理到数据持久化的完整流程。

## 架构图

```
┌─────────────┐     ┌─────────┐     ┌─────────────┐     ┌──────────┐
│  数据源    │ ──> │   DIS   │ ──> │FunctionGraph│ ──> │ GeminiDB │
│ (Producer) │     │  (流)   │     │  (函数)     │     │  (存储)  │
└─────────────┘     └─────────┘     └─────────────┘     └──────────┘
```

## 组件说明

### 1. 数据源 (Producer)
- 模拟社交媒体事件数据
- 推送到 DIS 流

### 2. DIS (数据接入服务)
- 实时数据流接入服务
- 提供流式数据通道
- 分片数：1（可扩展）

### 3. FunctionGraph
- 无服务器函数计算服务
- 消费 DIS 流事件
- 解析并写入 GeminiDB

### 4. GeminiDB
- 文档数据库
- 使用 Cassandra API
- 存储结构化事件数据

## 数据流

1. Producer 生成模拟事件
2. 事件推送到 DIS 流
3. FunctionGraph 触发执行
4. 函数解析 JSON 数据
5. 数据写入 GeminiDB

## 技术规格

| 组件 | 规格 |
|------|------|
| DIS 分片数 | 1 |
| 函数运行时 | Node.js 18.15 |

| 函数超时 | 10 秒 |
| GeminiDB 节点 | 3 |
| 存储容量 | 100 GB |
